## 1. 統計量的意思和算法

這一節依「從簡單到複雜」的順序解釋每個統計量，每個都附上論文或我們的例子。論文用 Jamovi 2.3（R 4.1）計算；我們用 numpy、scipy 照同樣的定義計算，對應的程式寫在每段最後。

### 1.1 平均數 M、標準差 SD

- **M**：所有人分數的平均。
- **SD**：每個人和平均差多少的典型大小。SD 越小，代表大家的分數越接近。

**例子**：我們 arm A 的 strength（1-10 分）M = 7.75、SD = 0.39，代表 261 個 persona 幾乎都給 7-8 分。

**為什麼重要**：SD 太小時，分數沒有個體差異，任何變項都很難預測它。這叫「全距限制」（restriction of range），會壓低 r 和 β。

### 1.2 相關係數 r

**問的問題**：兩個變項是否一起變動？

**算法**：

```
r = 兩者的共變數 ÷ (需求的 SD × 結果的 SD)
```

- 範圍 −1 到 +1。正值代表一起升高，負值代表一個升高另一個降低，0 代表沒有線性關係。
- **r² = 解釋的變異比例**。r = .57 代表需求能解釋結果約 32%（.57²）的個體差異。
- **顯著性**：t = r × √(n − 2) ÷ √(1 − r²)，df = n − 2。n = 261 時，|r| ≥ .12 就會 p < .05。

**例子**：論文 5a 的 vision 和 dedication，r = .57。

**限制**：
- r 沒有控制任何東西，所以兩個變項可能只是因為共同的第三個變項而相關。例如 vision 和 expertise 本身高度相關，所以 vision 和 dedication 的 r 裡面，混有 expertise 的貢獻。
- r 不代表因果。

程式：`np.corrcoef`、`scipy.stats.pearsonr`。

### 1.3 多元迴歸：同時放進六個需求

**問的問題**：六個需求一起考慮時，每個需求各自對結果有多少影響？

**模型**：

```
結果 = b0 + b1×protection + b2×affiliation + b3×status + b4×vision + b5×expertise + b6×fairness + 誤差
```

- 用最小平方法（OLS）求 b0 到 b6，讓「預測值和實際值的差」平方加總最小。
- **「控制其他需求」的意思**：b4 是「另外五個需求維持不變時，vision 每增加 1 分，結果增加幾分」。

下面 1.4 到 1.10 都是從這個迴歸算出來的。

### 1.4 截距 b0

**意思**：六個需求都是 0 分時，結果的預測值。

FFNI 是 1-7 分，沒有人會是 0 分，所以截距本身沒有實質意義，只是讓迴歸線的位置正確。論文和我們的表都列出來，只是為了完整。

### 1.5 未標準化係數 b

**意思**：控制其他五個需求後，這個需求每增加 **1 分**，結果增加幾分。單位是原始量表的分數。

**例子**：論文 5a fairness → ethics，b = 0.53。fairness 需求高 1 分（1-7 分制），理想領導者的 ethics 評分高 0.53 分（1-10 分制）。

**限制**：b 的大小受量表單位影響，不同量表之間不能直接比較。所以要看 β（1.7）。

### 1.6 標準誤 SE

**意思**：b 估計得多不精確。如果用另一批同樣大小的樣本重做，b 大概會在 ±SE 的範圍內變動。

- **95% 信賴區間 ≈ b ± 1.96 × SE**。例如 fairness → ethics：0.53 ± 1.96 × 0.15 = [0.24, 0.82]，不包含 0，所以顯著。
- **SE 變大的原因**：樣本少、殘差大（模型解釋得不好）、**預測變項彼此高度相關**。最後一項叫共線性。論文的需求之間相關 .21-.72，所以每個需求的 SE 都偏大，獨特效果不容易顯著。

### 1.7 標準化係數 β

**意思**：把所有變項都換成標準分數（平均 0、SD 1）後的 b。也就是控制其他五個需求後，這個需求每增加 **1 個 SD**，結果增加幾個 SD。

**算法**：

```
β = b × SD(需求) ÷ SD(結果)
```

**為什麼要用 β**：沒有單位，不同量表之間可以比較大小。可以參考 r 的基準：.10 小、.30 中、.50 大。

**β 和 r 的關係**：
- 只放一個需求時（Model 1），β = r。
- 放六個需求時（Model 2），β 通常比 r 小，因為和其他需求共享的部分被扣掉了。
- **β 也可能比 r 大，甚至正負號相反**，這叫抑制效果（suppression）。
  - 論文 5a intelligence 的 affiliation：r = +.30，β = −.19。affiliation 本身和 intelligence 正相關，但這是因為它和 vision、fairness 重疊；扣掉重疊之後，剩下的獨特部分反而是負的。
  - 我們 arm A strength 的 affiliation：r = −.10，β = −.31。

程式：`src/stats.partial_betas`（把變項標準化後做迴歸）。

### 1.8 t 值、自由度 df、p 值

**算法**：

```
t = b ÷ SE
df = n − k − 1 = n − 7（k = 6 個需求，再減 1 個截距）
p = 在 t 分配（df）下，|t| 至少這麼大的雙尾機率
```

n = 261 時 df = 254；n = 367 時 df = 360。

**p 的意思**：**假設這個需求的真實效果是 0**，抽樣碰巧得到這麼大（或更大）的效果的機率。

**常見誤解**：
- p 不是「假設成立的機率」，也不是「結果錯的機率」。
- p 不是效果大小。樣本很大時，很小的效果也會 p < .001。
- p = .049 和 p = .051 沒有實質差別，只是剛好落在 .05 的兩邊。

**星號**：\* p < .05，\*\* p < .01，\*\*\* p < .001。

**多重比較**：做 14 個檢定時，就算全部沒有真實效果，至少一個碰巧 p < .05 的機率是 1 − 0.95¹⁴ ≈ 51%。論文和我們都沒有校正。

程式：`study5_tables.ols`。

### 1.9 R²：六個需求一起解釋了多少

**意思**：六個需求合起來，能解釋結果的多少比例的個體差異。範圍 0 到 1。

**算法**：

```
R² = 1 − 殘差的平方和 ÷ 結果的總平方和
```

**例子**：論文 5a sensitivity 的 R² = .26，六個需求解釋了 26%；我們是 .81。

論文沒有報告調整後的 R²（adjusted R²）。6 個預測變項、261 人時，調整的幅度很小（約 .01-.02）。

### 1.10 ΔR²：這個需求的獨特解釋力

**問的問題**：其他五個需求已經在模型裡了，再加入這個需求，R² 會增加多少？

**算法**（階層迴歸）：

```
第一步：只放其他五個需求，得到 R²(5)
第二步：六個需求全放，得到 R²(6)
ΔR² = R²(6) − R²(5)
F = ΔR² ÷ (1 − R²(6)) × (n − 7)，df = (1, n − 7)
```

- ΔR² 等於這個需求的「半偏相關」的平方：只屬於它、不和其他需求共享的那部分。
- **F = t²**，所以 ΔR² 的 p 和 β 的 p 完全相同。論文說某個需求「uniquely predicts」，指的就是 ΔR² 顯著。

**為什麼 ΔR² 通常很小**：需求之間共享的變異不算在任何一個需求頭上。

**例子**：論文 5a 的 protection 和 strength，r = .38（單獨解釋 14%），但 ΔR² 只有 .03（獨特解釋 3%），其餘 11% 和其他需求共享。

程式：`src/stats.partial_betas`（對每個需求各拿掉一次重新計算）。

### 1.11 Relative weights（RW、RW%、RW CI）

**問的問題**：R² 怎麼公平地分給六個需求？

**為什麼需要**：ΔR² 只算獨特的部分，共享的部分沒有分給任何人。需求之間高度相關時，六個 ΔR² 加起來遠小於 R²，看不出誰最重要。

**算法**（Johnson, 2000）：
1. 把六個相關的需求轉換成六個彼此不相關的成分，而且每個成分盡量接近原本的某一個需求。
2. 用這六個成分預測結果，每個成分的解釋力可以清楚分開。
3. 把成分的解釋力，按照它和原本需求的對應關係，分回六個需求。

- **RW**：分到的 R²。六個 RW 加起來等於 R²。
- **RW%**：RW ÷ R²，也就是佔解釋量的百分比。
- **RW CI**：論文用 bootstrap（重新抽樣 10,000 次）得到的 95% 信賴區間，不包含 0 就算重要。**我們沒有算這一項。**

**例子**：論文 5a sensitivity 的 affiliation，ΔR² = .00（沒有獨特貢獻），但 RW = .05（佔 19.73%），因為它和 vision、expertise 共享的解釋力被分了一部分給它。

程式：`src/stats.relative_weights`。

### 1.13 SEM β（Table 3）

**意思**：結構方程模型（SEM）的係數。SEM 不直接用題目平均分數，而是從題目估計「潛在變項」，所以校正了測量誤差。

**為什麼比 Model 1 大**：量表不可靠時，測量誤差會把相關壓低（衰減）。粗略的校正公式是：

```
校正後的 r ≈ 觀察到的 r ÷ √(α需求 × α結果)
```

**例子**：論文 5c affiliation → benevolence，Model 1 = .31，affiliation 的 α = .61、benevolence 的 α = .60，校正後約 .31 ÷ √(.61 × .60) ≈ .51。SEM 報告的是 .68，比粗略校正更高，因為 SEM 用的是完整的測量模型，不是這個簡化公式。

**我們沒有算 SEM**：我們的 α 幾乎都接近 1，測量誤差很小，SEM 和 Model 1 的差距也會很小。

### 1.14 Cronbach's α 和 McDonald's ω（信度）

**問的問題**：同一個量表的幾道題，是否在測同一件事？

**算法**：

```
α = k ÷ (k − 1) × (1 − 各題變異數的總和 ÷ 總分的變異數)，k = 題數
```

- 各題答案越一致，α 越接近 1。一般 .70 以上算可以接受。
- 題數越多，α 通常越高。
- **ω** 和 α 類似，但不假設每一題的貢獻相同，論文同時報告兩者。

**例子**：
- 論文 Sample E 的 vision 只有 α = .43，很低。
- 我們的 α 大多是 .96-1.00，代表同一個 persona 對同一量表的每一題幾乎給完全相同的分數。這在真人身上很少見。

程式：`src/stats.cronbach_alpha`。

### 1.15 潛在因素相關（Table 8 上三角）

**意思**：把 CFA（驗證性因素分析）估計出來的潛在變項拿來算相關，同樣校正了測量誤差，所以通常比下三角的 Pearson r 高。

**例子**：論文 Sample B 的 affiliation–vision，Pearson r = .72，潛在相關 = .85。

我們只算了 Pearson r，沒有做 CFA。

### 1.16 計分

- 每個量表取題目的平均分數。
- 有效性量表的 moral character 第 1、3 題是反向題，以 8 − 原始分數計分（`studies/ffni_mediation/instruments/effectiveness_styles.json` 的 `reverse`）。

## 8. 去掉 OCEAN 之後的相關（我們自己的分析，論文沒有）

來源：`tools/ocean_confound.py`。

### 8.1 為什麼要做

每份量表都是在一個新的 fork 上作答，所以需求和依變項之間只能透過兩邊共有的東西產生相關：persona 的 OCEAN 設定和描述文字。這一節用來回答一個問題：我們得到的 r，有多少是 OCEAN 造成的？

### 8.2 三個量怎麼算

把每個 OCEAN 特質編成虛擬變項（medium、high 各一個，low 當參照），一共 10 個預測變項。

- **R²(OCEAN)**：拿需求（或依變項）對這 10 個變項做迴歸，看 OCEAN 解釋了多少變異。
- **r|OCEAN**（淨相關）：需求和依變項各自對 OCEAN 做迴歸，取殘差，再算兩組殘差的相關。意思是「OCEAN 設定完全相同的兩個 persona 之間，需求和依變項還有多少相關」。
- **r(OCEAN parts)**：兩邊 OCEAN 預測值之間的相關。它衡量需求和依變項是不是由同一組特質撐起來的：接近 1 代表兩邊靠的是同一組特質，接近 0 代表各靠各的。

> 描述文字沒有被模型化。所以 r|OCEAN 裡剩下的部分，還包含了描述文字造成的共同變異。

## 9. 複製判準（我們自己的判斷，論文沒有規定）

來源：`tools/replication_criteria.py`。判準的文獻和完整討論在 `docs/study5-criteria.md`。

### 9.1 三個判準怎麼算

- **A：方向 + 顯著**（Open Science Collaboration, 2015）。論文顯著的格子：我們同方向而且 p < .05 才算複製成功。論文不顯著的格子：我們也 p ≥ .05 才算成功。arm A 用 Model 2 的 ΔR² p，arm B 用 Model 2 β 的 p（和 `results/replication/*/summary.json` 的 `replicated` 一樣）。
- **C(r)：r 落在論文的 95% 預測區間**（Patil, Peng & Leek, 2016）。預測區間回答的是「如果真實效果和論文一樣，換一批 n 個人，r 會落在哪裡」。它同時考慮論文和我們兩邊的抽樣誤差，所以比論文的信賴區間寬。
  - 把論文的 r 轉成 Fisher z：z = atanh(r)。
  - 區間：z ± 1.96 √(2/(n − 3))，再用 tanh 轉回 r。n 用我們的樣本數（261 或 367），√2 是因為兩邊各有一份抽樣誤差。
- **C(β)：β 落在論文的 95% 預測區間**：論文 β ± 1.96 √(SE論文² + SE我們²)。
  - arm A 的論文 SE(β)：Table 13 給的是 b 的 SE，所以用 SE(b) × β / b 換算。
  - arm B 的論文 SE(β)：Table 3 只給 β 和 p，所以從 p 反推，SE = |β| / t(p/2, n − 7)。
  - 有兩格 p < .001（affiliation → team_building、fairness → moral_character），還有 |β| < .05 的格子，反推不出 SE，所以改用其他格子的中位數 .054。這些格子的區間是近似值。

> **沒有計算的判準**：B（我們的信賴區間包含論文的值）、D（等價檢定，Lakens, 2017）、E（small telescopes，Simonsohn, 2015）。這三個在 `docs/study5-criteria.md` 有討論，但沒有逐格算出來。
